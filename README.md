# PG

PG Finder is a responsive Next.js promotional site for a direct PG marketplace with live room availability.

## Live site

[https://prakash116.github.io/PG/](https://prakash116.github.io/PG/)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

The site is automatically deployed to GitHub Pages when `main` is updated.
